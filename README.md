#  Proyecto: Reconectando con la Realidad — Bienestar Digital

##  Descripción del Proyecto
Plataforma web académica orientada a concientizar a la comunidad universitaria sobre el uso saludable y consciente de la tecnología, ofreciendo herramientas contra la fatiga visual, alteración del sueño por luz azul y adicción digital.
